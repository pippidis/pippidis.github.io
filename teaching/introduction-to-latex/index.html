Introduction to LaTeX

A practical starting point for writing structured documents, equations, figures and tables.

Learn the building blocks of a LaTeX document through short explanations and hands-on exercises. The introductory workshop focuses on getting a document working, understanding its structure and learning how to diagnose errors. Intermediate material provides a next step for longer projects.

What we cover

  • Document classes, commands, environments and packages.
  • Equations, mathematical notation, figures and tables.
  • Document structure, compilation, error handling and file organisation.
  • Further practice: cross-references, custom commands, code listings and larger projects.

Before you start

No previous LaTeX experience is required for the introductory material. For the intermediate exercises, first become comfortable creating and compiling a simple document.
