Citation management with LaTeX

Build a reference library and use it consistently in a LaTeX document.

This workshop follows a reference from discovery to a finished bibliography. It combines practical work with bibliography entries and citation keys, reference management in JabRef, and the differences between BibTeX, natbib and BibLaTeX with Biber.

What we cover

  • Finding references and checking imported metadata.
  • Choosing entry types, writing author names and using stable citation keys.
  • Managing a .bib library and citing sources in a document.
  • Compilation workflows and changing between citation systems.

Before you start

Basic familiarity with a LaTeX document is useful. The exercise archive includes a starting document and a bibliography file; a separate archive contains worked solutions.
